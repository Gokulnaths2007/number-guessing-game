
# Number Guessing Game

## Description
A beginner-friendly Python game where the computer
selects a random number between 1 and 100.
The player guesses the number using hints.

## Features
- Random number generation
- Hints for guesses that are too high or too low
- Counts the number of valid guesses
- Handles invalid text input
- Validates the guessing range (1-100)

## Technology
- Python

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python number_guessing.py

## Concepts Used
- Variables
- while loop
- if-elif-else conditions
- try-except error handling
- random module
- User input
